# Popê Beauty

E-commerce de maquiagem e beleza — Next.js, Vercel e Supabase.

> Projeto em desenvolvimento. A vitrine inicial utiliza exemplos ilustrativos; pedidos, pagamentos e sincronização com marketplaces não estão ativos.

## Etapas

1. Estrutura da vitrine e painel administrativo.
2. Projeto Supabase dedicado: Auth, catálogo, estoque e pedidos com RLS.
3. Integração Shopee e Mercado Livre (mediante credenciais e homologação).
4. Pagamentos, frete, expedição e operação em produção.
